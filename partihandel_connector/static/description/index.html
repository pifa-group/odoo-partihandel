Partihandel Connector

Connect Odoo to Partihandel, the order and warehouse system for wholesalers

Partihandel runs the daily work of a wholesaler: orders, picking, lots and pallets, purchasing and the B2B webshop. Odoo keeps the books. This module sets up the connection between the two in one step, so customers, suppliers, products and invoices you create in Partihandel show up in Odoo without retyping.

Requires a Partihandel account. The module itself is free.

What it does

  • Adds a Partihandel section to Settings.
  • Creates a dedicated user, Partihandel Integration, so everything Partihandel changes in Odoo is recorded under its own name and can be switched off without touching anyone else's access.
  • Gives that user only what the integration needs: create and update contacts and products, and create and post customer invoices. It is not an administrator and cannot log in to the web client.
  • Issues an API key for the user and shows the four values to paste into Partihandel. Running the setup again replaces the key, which is how you rotate it.

How to connect

  1. Install the module and open Settings > Partihandel.
  2. Check the Partihandel address (the one you log in to Partihandel with) and press Connect to Partihandel.
  3. Press Create API key.
  4. Press Open Partihandel, paste the URL, database, login and API key, then press Save and Test connection.

Good to know

  • Your Odoo must be reachable over https. Partihandel never sends an API key over plain http.
  • The integration user is an internal user, so on a paid Odoo plan it counts as one user.
  • The user is created in the company you are working in when you run the setup.
  • To disconnect, archive the Partihandel Integration user or delete its API key under Settings > Users.
